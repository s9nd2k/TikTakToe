# 🎮 Крестики-Нолики (Tic-Tac-Toe)

Современное веб-приложение «Крестики-Нолики» с расширенным функционалом, разработанное с использованием **React**, **TypeScript**, **Tailwind CSS** и **Vite**.

## 📋 Описание

Классическая игра «Крестики-нолики» с современным дизайном и расширенными возможностями. Приложение поддерживает систему авторизации, различные размеры поля, звуковое сопровождение, статистику и таблицу рекордов.

---

## ✨ Главные особенности

### 🔐 Система авторизации
- Регистрация новых пользователей
- Вход по логину и паролю
- Сохранение сессии (localStorage)
- Валидация данных

### 📐 Выбор размера поля
- **3×3** — классический режим (3 в ряд)
- **4×4** — расширенный режим (4 в ряд)
- **5×5** — большой режим (4 в ряд)
- **6×6** — большой режим (5 в ряд)
- **7×7** — огромный режим (5 в ряд)

### 🔊 Звуковое сопровождение
- Звук хода
- Звук победы (мелодия)
- Звук ничьей
- Звук ошибки
- Возможность отключения звуков

### 📊 Статистика
- Общее количество игр
- Количество побед, поражений, ничьих
- Процент побед
- Общее время игры
- Лучшее время победы
- Количество ходов в каждой игре

### 🎨 Стилевое оформление
- **Тёмная тема** — стильный тёмный дизайн с glassmorphism эффектами
- **Светлая тема** — чистый светлый дизайн с мягкими градиентами
- Плавное переключение между темами
- Сохранение выбранной темы

### 🏆 Таблица рекордов
- Топ-20 лучших результатов
- Сортировка по времени победы
- Информация об игроке, размере поля, количестве ходов и дате
- Выделение текущих записей пользователя

## 🚀 Установка и запуск

### Требования
- Node.js >= 18
- npm >= 9

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/tic-tac-toe.git

# Перейти в директорию проекта
cd tic-tac-toe

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Собрать production-версию
npm run build
```

## 🎯 Как играть

1. **Зарегистрируйтесь** или войдите в систему
2. **Настройте игру**: выберите размер поля, имена игроков
3. **Начните игру** и делайте ходы по очереди
4. **Соберите** нужное количество символов в ряд для победы
5. **Следите за статистикой** и бейте рекорды!

## 🔧 Конфигурация

### Темы
Тема сохраняется в `localStorage` и применяется при следующем входе:
```javascript
localStorage.setItem('ttt_theme', 'dark'); // или 'light'
```

### Данные пользователей
Все данные хранятся локально в браузере:
- `ttt_users` — список пользователей
- `ttt_records` — игровые записи
- `ttt_stats` — статистика игроков
- `ttt_current_user` — текущий пользователь
- `ttt_theme` — выбранная тема
