## 📋 Описание

Классическая игра «Крестики-нолики» с **премиальным дизайном**, расширенным функционалом и современными визуальными эффектами. Приложение включает систему авторизации, различные размеры поля, звуковое сопровождение, подробную статистику и таблицу рекордов.

---

## 🎨 Визуальные эффекты

### ✨ Реализованные эффекты:
- **Glassmorphism** — размытое стекло с прозрачностью
- **Mesh Gradients** — сложные многослойные градиенты фона
- **Анимированные блобы** — морфирующие фоновые фигуры
- **Конфетти** — эффект при победе
- **Неоновое свечение** — подсветка выигрышных клеток
- **3D трансформации** — hover-эффекты с перспективой
- **Плавающие символы** — анимированные X и O на фоне
- **Вращающиеся кольца** — декоративные элементы
- **Shimmer эффект** — мерцание на прогресс-барах
- **Градиентные анимации** — переливающиеся кнопки и элементы
- **Микроанимации** — bounce, scale, fade на всех интерактивных элементах
- **Анимированная сетка** — фоновый паттерн

## ✨ Главные особенности

### 🔐 Система авторизации
- Регистрация новых пользователей с валидацией
- Вход по логину и паролю
- Сохранение сессии (localStorage)
- Анимация загрузки при входе
- Показ/скрытие пароля

### 📐 Выбор размера поля
- **3×3** — классический режим (3 в ряд)
- **4×4** — расширенный режим (4 в ряд)
- **5×5** — большой режим (4 в ряд)
- **6×6** — большой режим (5 в ряд)
- **7×7** — огромный режим (5 в ряд)

### 🔊 Звуковое сопровождение
- Звук хода (Web Audio API)
- Мелодия победы
- Звук ничьей
- Звук ошибки
- Переключатель звуков

### 📊 Статистика
- Общее количество игр
- Количество побед, поражений, ничьих
- Процент побед с прогресс-баром
- Общее время игры
- Лучшее время победы
- Визуальные карточки с градиентами

### 🎨 Стилевое оформление
- **Тёмная тема** — mesh gradient + glassmorphism
- **Светлая тема** — мягкие пастельные градиенты
- Плавное переключение с анимацией
- Сохранение выбранной темы

### 🏆 Таблица рекордов
- Топ-20 лучших результатов
- Медали для топ-3 (🥇🥈🥉)
- Сортировка по времени победы
- Выделение записей текущего пользователя
- Информация: игрок, поле, время, ходы, дата

## 🚀 Установка и запуск

### Требования
- Node.js >= 18
- npm >= 9

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/tic-tac-toe.git

# Перейти в директорию проекта
cd tic-tac-toe

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Собрать production-версию
npm run build

# Предпросмотр production-сборки
npm run preview
```

## 🎯 Как играть

1. **Зарегистрируйтесь** или войдите в систему
2. **Настройте игру**: выберите размер поля, имена игроков
3. **Включите/выключите** звуки
4. **Начните игру** и делайте ходы по очереди
5. **Соберите** нужное количество символов в ряд для победы
6. **Наслаждайтесь** конфетти при победе! 🎉
7. **Следите за статистикой** и бейте рекорды!

## 🎨 Особенности дизайна

### Цветовая палитра
- **Индиго/Фиолетовый** — основные акценты
- **Розовый/Красный** — символ O
- **Синий/Индиго** — символ X

- Glassmorphism с backdrop-blur
- Mesh gradients для фонов
- Neon glow для интерактивных элементов
- 3D transforms при hover
- Spring animations для появления
- Particle effects (конфетти)
- Morphing blobs на фоне

## 🔧 Конфигурация

### Темы
Тема сохраняется в `localStorage` и применяется при следующем входе:
```javascript
localStorage.setItem('ttt_theme', 'dark'); // или 'light'
```

### Данные пользователей
Все данные хранятся локально в браузере:
- `ttt_users` — список пользователей
- `ttt_records` — игровые записи
- `ttt_stats` — статистика игроков
- `ttt_current_user` — текущий пользователь
- `ttt_theme` — выбранная тема
